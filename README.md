# Cortex Lab — квиз-лендинг

Одностраничный сайт с квизом на 5 вопросов и формой заявки.

## Файлы

- `index.html` — весь сайт (стили и скрипты внутри)
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите все файлы в корень.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Настройки

В `index.html`, в блоке `CFG` в начале скрипта:

- `endpoint` — адрес формы Formspree (сейчас `https://formspree.io/f/xnpjdlye`). Заявки приходят на почту, привязанную к форме в Formspree, адрес нужно подтвердить по письму.
- `email` — запасной адрес: если отправка не удалась, открывается почтовая программа с готовым письмом.

Контакты (WhatsApp, e-mail, Telegram, MAX) находятся в футере страницы.

## Если появится свой хостинг в РФ

Заявки можно принимать на своём сервере через скрипт на PHP, Битрикс24 или Яндекс Cloud Functions: достаточно заменить `endpoint`.
